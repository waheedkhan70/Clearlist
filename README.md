# Clearlist

A small, real to-do app for **Global Hack Week: Hacktoberfest — Challenge 1: Build a Mini App with Cursor**.

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500`.

## What it does

- Add, complete, edit (double-click), and delete tasks
- Filter All / Active / Done
- Persist tasks in `localStorage` as JSON (survives refresh)
- Keyboard: Enter to add or save an edit, Escape to cancel an edit
